# uBlock and filter-list licensing audit

9 October 2026. This is an engineering inventory, not legal advice or a ruling about derivative works. No uBlock code or new assets were copied into Paper in this audit. Obtain counsel and a file-specific bill of materials before distribution of any copied or ported source.

| Material | Official license evidence | Consequence to review before reuse |
| --- | --- | --- |
| uBlock Origin source, including its parser, scriptlet and redirect engines | [uBlock `LICENSE.txt`](https://github.com/gorhill/uBlock/blob/master/LICENSE.txt); source headers commonly specify GPL v3 or later | Preserve notices and modification history; assess GPL-covered combination and corresponding-source obligations before copying or porting expression into Paper. |
| uBlock Origin Lite | [Official MV3 build](https://github.com/gorhill/uBlock/blob/master/platform/mv3/README.md) uses the same uBlock source; [uBOL-home](https://github.com/uBlockOrigin/uBOL-home) states GPL-3.0 | Safari packaging is not a separate permissive parser license. Audit generated output and input assets separately. |
| uAssets filters and scriptlet-related rules | [uAssets `LICENSE`](https://github.com/uBlockOrigin/uAssets/blob/master/LICENSE) is GPL v3; implementations in uBlock `src/js/resources` inherit file-specific headers | Do not bundle or execute copied resources without GPL and attribution review. Lists can contain references to other subscriptions with different terms. |
| EasyList and EasyPrivacy | [EasyList license](https://easylist.to/pages/licence.html): GPL v3-or-later **or** CC BY-SA 3.0-or-later | Paper already bundles subsets; retain source and attribution, identify the chosen license for distribution, and review update/redistribution requirements. |
| Public Suffix List | [PSL license](https://publicsuffix.org/list/) and bundled MPL 2.0 header | Preserve notice and comply with MPL file-level source terms for modifications. |
| Auxiliary uBlock libraries | Check each vendored file's license, e.g. [`src/lib`](https://github.com/gorhill/uBlock/tree/master/src/lib) | Do not assume the repository's top-level license describes every third-party dependency. Avoid importing unused libraries. |

The audited uBlock checkout contains separately licensed support libraries under `src/lib` (for example CSS parsing, editor, compression, and public-suffix helpers). Some carry permissive notices while others offer dual terms. A bulk copy of `src/js` or generated uBOL rulesets would need a transitive inventory of those files and the source lists used to build them. The GPL status of the uBO parser and scriptlet files cannot be bypassed by compiling them into generated JavaScript or translating them mechanically to Swift.

The [GPL v3 text](https://www.gnu.org/licenses/gpl-3.0.html) sets notice, license-copy, and corresponding-source obligations for distribution of covered works, including modified works. Whether a particular Swift port or combined app is a derivative/covered work is fact-specific. Treat a line-by-line translation as a copying risk; architectural ideas, public interfaces, and independently written behavior can be considered without copying implementation expression, but that distinction still needs review if reuse grows substantial.

For Paper's planned V2, use official syntax descriptions and observed input/output behavior as specifications; implement and test Swift code independently. Maintain a source manifest for every bundled list and its license, date, URL, hashes, notices, and update terms. Never pull JavaScript code from remote filter rules into `WKUserScript`. A future proposal to copy a source file must identify its exact revision and license, redistribution model, corresponding-source plan, and attribution placement before code is merged.

**Distribution status:** Paper's own repository/distribution license was not resolved by this audit; a compatible licensing and source-delivery plan would be required if GPL implementation code were incorporated into a distributed app. Paper now records the CC BY-SA 3.0 option for its bundled EasyList/EasyPrivacy data in the root [Third-Party Notices](../THIRD_PARTY_NOTICES.md). The app's own source and artwork still have no project-wide license. This unresolved app license blocks *direct source reuse*, not the independently designed, documentation-only V2 proposal.
