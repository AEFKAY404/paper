# Phase 2E visual blocking

`VisualBlockerEngine` adds one Paper-owned, main-frame `WKUserScript` at document end when global protection applies. Standard tabs honor the registrable-domain bypass; private tabs use global protection and ignore saved exceptions. The script is removed from future navigations when policy changes, and its live DOM replacements are restored when protection is disabled. This layer supplements `WKContentRuleList` and static cosmetic CSS; it does not replace either.

## Detection and replacement

Only fixed, trusted selectors enter the candidate set: `ins.adsbygoogle`, `[data-ad-slot]`, `[data-testid="adBanner-wrapper"]`, exact ad-interstitial markers, `[data-ad-label="Advertisement"]`, and Reddit's `shreddit-ad-post`. A Reddit post additionally needs an exact Sponsored, Promoted, or Advertisement label. Elements must be visibly rendered and at least 80 × 35 pixels; very large areas are rejected. Dialogs, modal descendants, forms, video, and previously managed elements are excluded. Size, fixed positioning, or high z-index alone never qualifies. Generic filter-list selectors are not used as executable markup or script.

Paper moves original child nodes into a hidden holder and inserts a fixed Paper-owned status and keyboard-focusable “Collapse blocked content” button. The container retains its measured minimum dimensions initially. The button hides the container and lets layout reflow; it never clicks an ad. `data-paper-blocked` prevents duplicate replacement. Disabling protection restores the original nodes and inline style. An exact full-window interstitial can release an inline body `overflow:hidden` lock on collapse only when it is a direct body child and no other modal is detected. Other scroll locks are left unchanged.

The mutation observer batches added subtrees every 80 ms. Each batch considers at most 32 roots, walks at most 2,500 elements, evaluates at most 160 matching candidates, and inserts at most 24 placeholders per page. After 120 batches it disconnects. Excess work is dropped, leaving content visible; diagnostic mode reports budget exhaustion. It does not poll or continuously scan while scrolling. WebKit tears down document scripts on navigation/session destruction. The script explicitly excludes YouTube, including its player; no player state is changed.

## Verification and limits

Signed WebKit fixtures cover a banner, explicitly labelled sponsored card, modal exclusion, dynamic insertion, duplicate prevention, collapse without ad clicks, teardown, and narrowly scoped interstitial scroll unlock. The one-run local timing sample with 150 ordinary paragraphs and 1/5/10/20 ad slots reported script processing of **2/2/3/3 ms** and fixture creation to replacement of **174/71/70/82 ms**. These are single test-run observations, not frame-time, idle CPU, or memory benchmarks. Candidate and replacement counts equalled the ad-slot count; no batch budget was exceeded. Raw data: [local-performance.json](screenshots/phase2e/local-performance.json).

The signed-out 10 October 2026 smoke loaded six public pages with protection active and saved static viewport snapshots. The Guardian showed seven Paper placeholders in its DOM, including a top banner in the screenshot; its cookie-choice dialog stayed visible. Reddit showed no replacement in this changing feed sample, so sponsored-post coverage there remains unproven. The Verge, Amazon, and GitHub sign-in page showed zero replacements and retained their visible page content. YouTube loaded with this visual script absent. The smoke did not scroll, accept consent, sign in, click popups, or establish site-wide false-positive rates. [Raw observations](screenshots/phase2e/live-results.json), [Guardian](screenshots/phase2e/guardian.png), [Reddit](screenshots/phase2e/reddit.png), [The Verge](screenshots/phase2e/verge.png), [Amazon](screenshots/phase2e/amazon.png), [GitHub sign-in](screenshots/phase2e/github-login.png), [YouTube](screenshots/phase2e/youtube.png).

Cross-origin frames cannot be inspected by this main-frame script. Existing cosmetic CSS may already hide a region before the visual layer sees it. Script-only route changes can retain existing placeholders until page code replaces those nodes. Real-site scroll, typing CPU, WebContent memory, sticky-ad behavior, and physical VoiceOver use remain to be measured. Use the site's Privacy sheet to turn protection off if a false positive occurs.
